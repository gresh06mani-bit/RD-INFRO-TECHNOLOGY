# Student Placement Prediction

This machine learning project predicts whether a student will get placed based on academic performance, internships, aptitude score, and soft skills.

## Technologies Used

* Python
* Pandas
* Scikit-learn
* Matplotlib
* Seaborn
* Google Colab

## Tasks Completed

1. Problem Statement
2. Data Collection
3. Data Cleaning & Preprocessing
4. Exploratory Data Analysis
5. Feature Engineering
6. Model Training
7. Model Evaluation
8. Model Deployment
